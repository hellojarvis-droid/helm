# Helm Bug & Security Review

## Instructions

This report was generated by an AI subagent tasked with a comprehensive review of the Helm app codebase. The review covered:

- API Layer (routes, services, db, auth)
- Web Frontend (app, components, lib)
- Database Models
- Builder Feature (orchestration, versioning, execution)
- Auth & Permissions
- API Client
- Payment Flows
- Infra/Config
- Migration Safety

The subagent systematically read files, grepped for dangerous patterns, and analyzed code for security vulnerabilities, reliability issues, performance bottlenecks, and data integrity problems.

The report is organized by severity and category. Known Builder preview issues (vite host config, server-ready timeout, blob URL leak, zombie process logs) are skipped as requested.
